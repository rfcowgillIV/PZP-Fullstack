# Security Policy

Thanks for helping keep **PZP Fullstack** safe!

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Public issues can be
read by anyone, including people who'd misuse the information.

Instead, report it privately through GitHub:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and what could happen if
   someone abused it.

I'll reply as soon as I can, work on a fix, and credit you in the notes if
you'd like. If the "Report a vulnerability" button isn't there, open an issue
that just says you have a security report (no details) and I'll get in touch.

## Supported versions

Only the latest code on the `master` branch gets security fixes.
